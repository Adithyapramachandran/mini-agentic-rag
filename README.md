# mini-agentic-rag
Mini Agentic Pipeline using Gemini, ChromaDB, FastAPI and Streamlit.

This project implements a Mini Agentic Pipeline using Gemini 2.5 Flash, ChromaDB, Sentence Transformers, FastAPI, and Streamlit to demonstrate Retrieval-Augmented Generation (RAG) with tool-calling capabilities. When a user submits a query through the Streamlit interface, the request is sent to the FastAPI backend, where the Controller orchestrates the entire workflow. The Retriever searches a knowledge base of documents (refunds, plans, warranty, payment, support, contracts, etc.) stored in ChromaDB using semantic embeddings generated by the all-MiniLM-L6-v2 model and returns the most relevant documents. These retrieved documents, along with the user query, are passed to the Reasoner, which uses the Gemini LLM and versioned prompt templates to determine whether the answer can be generated directly from the knowledge base or if an external action is required. If the query is related to pricing or stock information, the Reasoner selects the TOOL path, and the Actor performs a lookup in a local CSV file (prices.csv) that acts as an external API, returning the required data. Otherwise, the system follows the KB path and uses Gemini to generate an answer based solely on the retrieved context. The Controller then compiles the final response, records retrieval results, reasoning decisions, tool execution details, latency information, and generated answers into trace logs, ensuring transparency and explainability. The project satisfies the assignment requirements by implementing a retriever with vector search, LLM-based reasoning, tool execution through CSV lookup, agentic decision-making between KB and tool usage, prompt versioning, logging, evaluation using test queries, and a user-friendly interface for demonstrating the complete workflow.
